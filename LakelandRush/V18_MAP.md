# V18 interactive map
All three map tabs support selection, zoom/reset and drag panning. Regional settlements, rail station and local bus stops become selectable; mapped places can request a fast travel arrival. Curated stops are checked for water/building/wall clearance. Otherwise choose nearby public mapped path/road point within 120m (350m regional), reject missing tiles and blocked candidates. These are provisional game spawn points, not surveyed entrances. No teleport to unlocated businesses. Waypoints persist in the running session and show direct distance and bearing in exploration minimap, not routed navigation. No changes to original geographic coordinates, Unity or other projects. Mobile physical testing remains required.
