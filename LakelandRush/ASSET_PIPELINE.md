# Asset pipeline

Reuse the existing headless Blender tools for reference-supported architectural production. Keep the source ID, model transform, source photograph rights, footprint and verification state in the asset manifest. Export GLB against a stable local origin, then validate scale, silhouette, UV/material response, collision and LOD on mobile. Use the Waterhead and Ambleside Blender scripts and [the photo capture brief](WATERHEAD_CAPTURE.md).
