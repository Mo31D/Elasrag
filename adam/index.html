Publishing audio for every device

Upload the audio file to the repository at adam/audio/english-001.wav. After GitHub Pages republishes, the lesson automatically loads it.

On GitHub, open the audio folder, choose Add file → Upload files, and commit. This is a public asset when the site is public.
